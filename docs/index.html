Reactor SDK
for React Native

Stream and steer Reactor real-time world models from iOS and Android. The React SDK's components and hooks, with the same names and props, running on react-native-webrtc.

View on GitHub Reactor docs

Free and open source. No subscription needed.

Install

npx expo install react-native-reactor react-native-webrtc @config-plugins/react-native-webrtc

Use

import { ReactorProvider, ReactorView } from 'react-native-reactor';

export default function App() {
  return (
    <ReactorProvider modelName="reactor/helios" jwtToken={getJwt}
                     connectOptions={{ autoConnect: true }}>
      <ReactorView style={{ width: '100%', aspectRatio: 16 / 9 }} />
    </ReactorProvider>
  );
}

What's inside

  • ReactorProvider, ReactorView, WebcamStream, ClipPlayer, useReactor, useReactorMessage
  • A TypeScript port of the Rust core, so no WebAssembly is needed on Hermes
  • Works on iOS and Android with Expo development builds
